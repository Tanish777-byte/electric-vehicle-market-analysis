Electric Vehicle Market Analysis

Project Overview

This project analyzes electric vehicle (EV) market data using Tableau Public to explore sales, pricing, battery performance, driving range, and customer ratings.

Tools Used

- Tableau Public
- Microsoft Excel / CSV
- GitHub

Dataset

The dataset contains information about EV manufacturers, vehicle categories, battery capacity, driving range, price, annual sales, and customer ratings.

Dashboard Objectives

- Compare EV sales by manufacturer.
- Analyze average price by vehicle category.
- Explore battery capacity versus driving range.
- Compare customer ratings.
- Analyze sales across market regions.
